use any of the assets found in the project. All National Chronicle material is NOT FREE for personal use.

## GETTING STARTED

First install the dependencies in the frontend and backend:

```bash
cd frontend
npm install
cd -
cd backend
npm install
```

Or if you prefer to run it in docker:

```bash
docker compose build --no-cache
docker compose up
```
